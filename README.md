# 합격 작전 (Exam Heist) — 가제

AI 장비로 시험을 치르며 감독관과 사후조사를 피해 **서울대 치대 합격**을 노리는 웹 기반 잠입/전략 시뮬레이션 게임.

> 이 게임은 **픽션**이다. 등장하는 장비·수치·규칙은 모두 게임용 가상 설정이며, 실존 제품 사양이나 실제 회피 절차를 담지 않는다. 실존 인물(실명·닉네임)은 등장하지 않는다.
