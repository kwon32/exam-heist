# Mission

## 한 줄 소개
플레이어는 수험생. AI 장비 파이프라인을 조립해 시험장의 감시를 뚫고, 시험 후 사후조사까지 넘겨 **서울대 치대에 합격**하면 클리어.

## 핵심 재미
1. **조립의 재미** — 촬영 → 전송 → AI 풀이 → 수신 → 출력 파이프라인을 부품 조합으로 설계
2. **긴장의 재미** — 안경 검사, 재난문자, 순찰 등 이벤트 속에서 의심 게이지 관리
3. **욕심의 딜레마** — 많이 맞힐수록 점수↑ 그러나 사후조사 리스크↑. 일부러 틀리는 전략도 유효
4. **두 단계 승부** — 시험장을 넘겨도 사후조사에서 합격 취소될 수 있음

## 클리어 조건
- 수능 성적이 서울대 치대 컷 이상
- 시험장 의심 게이지 100 미만 유지 (적발 없음)
- 사후조사 리스크 게이지가 임계치 미만 → 면접 통과 → **합격 엔딩**

## 실패 엔딩
- 시험장 적발 (즉시 실격)
- 성적 미달 (불합격)
- 사후조사 적발 → 합격 취소 / 응시 제한 / 형사 고발 (리스크 수준별)

## 원칙
- 전부 **가상 장비·가상 수치**. 실존 제품명·사양·실제 회피 방법은 다루지 않는다.
- 실존 인물(실명·닉네임) 미등장. 실제 사건은 배경 모티프로만 사용.
- 실제 정부 대책은 공개 보도 수준에서 **게임 이벤트(방해 요소)**로 반영.
