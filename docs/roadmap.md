# Roadmap

| 마일스톤 | 내용 | 완료 기준 |
|---|---|---|
| **M0 기획** | 컨셉·디자인·정책 조사 문서화, 레포 생성 | 이 문서들 ✅ |
| **M1 뼈대** | Vite+Phaser+TS 세팅, 씬 전환, core 로직(게이지·파이프라인) + 테스트 | 타이틀→시험→엔딩 흐름 동작 |
| **M2 시험장 MVP** | 수능 1교시 1개: 감독관 순찰, 의심 게이지, 빌드 1종(올인원 글래스), 안경 검사 이벤트 | 한 판 플레이 가능 |
| **M3 파이프라인** | 전체 부품·조합, 미니게임 4종, 보안 이벤트 1–17 | 빌드 3종 플레이 가능 |
| **M4 사후조사·엔딩** | 욕심/사후 게이지, 면접, 엔딩 분기 | 클리어/실패 엔딩 전부 |
| **M5 진행·경제** | 내신→모의고사→수능 루트, 상점·해금, 보안 Lv1–4 | 처음부터 끝까지 플레이 |
| **M6 폴리시** | 아트·사운드·밸런싱·모바일 대응, 배포 | GitHub Pages 공개 |
